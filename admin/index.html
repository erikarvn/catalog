Cuidado do catálogo

Abrindo o painel…

Antes de entrar, conecte o catálogo ao Supabase. É só uma vez:

  1. Crie um projeto grátis em supabase.com.
  2. Em Project Settings → API, copie a Project URL e a chave anon ou publishable.
  3. Cole as duas em config/supabase.js. Não use a chave service_role nem uma chave secret.
  4. No SQL Editor, cole o arquivo supabase/schema.sql e execute.
  5. Em Authentication → Users, crie um usuário com e-mail e senha, já confirmado.
  6. No SQL Editor, execute a instrução do README que coloca o seu e-mail como administrador.

O passo a passo completo está no README.md. Quando terminar, atualize esta página.
